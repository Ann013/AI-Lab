# AI Art Companion

AI Art Companion is an AI-powered artistic development platform that provides intelligent artwork analysis, creative guidance, and community interaction for artists.

## Features
- Perspective correction analysis
- Anatomy and proportion checking
- Mood & color palette suggestions
- Artwork upload and gallery system
- Artist dashboard and profile management
- Community artwork sharing
- AI-generated artistic feedback

## Technologies Used
- React
- JavaScript / TypeScript
- Node.js
- Express.js
- MySQL
- Tailwind CSS
- Google Generative AI (Gemini)

## Installation

```bash
npm install
npm start
````
